AMORCHECK WEBSITE - GITHUB UPDATE V4

This package is ready to replace the current website files in your GitHub repository.

UPLOAD TO GITHUB
1. Open your AmorCheck GitHub repository.
2. Delete or replace the old website files.
3. Upload every file and folder from this package to the repository root.
4. Keep the folder structure exactly as provided, especially assets/css, assets/js and assets/img.
5. Commit the changes.
6. Wait about 1 to 3 minutes for GitHub Pages to refresh.
7. On iPhone Safari, close the old tab and reopen the site, or clear the website cache if an old design still appears.
